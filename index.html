GitHub Pages & 獨立執行指南

如何將「決策管理試題練習」放到 GitHub 並以獨立 App 視窗開啟？

本檔案已命名為 index.html，單一檔案完整內建《英中專業術語.pdf》前導練習區與全部 113 題決策管理試題練習卡及雙語語音引擎。

1 上傳 `index.html` 到 GitHub 產生專屬網址

  1. 登入 GitHub，點擊右上角 + 號選擇 New repository。
  2. 輸入儲存庫名稱（例如 decision-practice），勾選 Public 並點擊 Create repository。
  3. 點擊 uploading an existing file，將本檔案 index.html 拖曳上傳，點擊 Commit changes。
  4. 進入上方 Settings ➔ 左側 Pages，在 Branch 選擇 main 並按 Save。
  5. 等待約 1 分鐘，即可獲得專屬網址：
    https://<您的GitHub帳號>.github.io/decision-practice/

2 免開瀏覽器視窗！做成獨立桌面 / 手機 App 捷徑

本 index.html 已內建 獨立 Web App (Standalone PWA) 標記，您可以讓它像原生軟體一樣不顯示任何瀏覽器網址列或分頁框直接啟動：

  • 手機 / iPad (iOS / Android)：打開 GitHub Pages 網址後，點選「分享」➔「加入主畫面 (Add to Home Screen)」。之後從桌面圖示點擊，就會直接以全螢幕獨立 App 開啟！
  • Windows / Mac 電腦獨立視窗執行：可建立捷徑或執行指令：
    msedge --app=https://您的帳號.github.io/decision-practice/
